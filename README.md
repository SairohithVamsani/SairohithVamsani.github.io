# Sairohith Vamsani – Portfolio

Static site: open index.html in any browser. No build step.

## Publish free on GitHub Pages
1. On GitHub, create a new public repository named exactly: SairohithVamsani.github.io
2. Click "Add file" > "Upload files", drag in ALL files from this folder (index.html, the .css/.js files, the resume PDF), and Commit.
3. Go to Settings > Pages. Under "Build and deployment", Source = "Deploy from a branch", Branch = main, folder = / (root). Save.
4. In 1-2 minutes the site is live at: https://sairohithvamsani.github.io/

## Add your photo
Put your headshot in this folder as profile.jpg, then in index.html find the comment
"Avatar: swap the monogram span..." and replace the SV monogram span with:
<img src="profile.jpg" alt="Sairohith Vamsani">
